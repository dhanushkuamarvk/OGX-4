# Co-Plan Pitch & Presentation Deck Outline (Resurrect 2026 — Problem 3)

## Slide 1 — Title & Hook
- **Co-Plan: From Prompt-and-Wait Chat to Steerable Shared-Workspace Collaboration**
- Resurrect 2026 · Problem 3 (Human-Agent Interaction)
- Core thesis: Complex work fails mid-flight—humans need **observability, mid-flight steering, selective protection, and reversible state**, not just longer chat prompts.

## Slide 2 — The Problem With Prompt-and-Wait Chat
- **Opaque execution:** Users wait blindly while the agent spends 30–60s writing in the wrong direction.
- **Destructive revision loops:** A mid-task requirement change forces re-prompting the whole document—often clobbering sections the human already verified.
- **Binary autonomy:** Chat either executes everything blindly or forces the human to micromanage every turn.

## Slide 3 — The Co-Plan Interaction Model
- **Three synchronized surfaces:**
  1. **Shared Hierarchical Plan Tree** (steps + substeps, accessible confidence indicators: icon + High/Medium/Low + bar + numeric tooltip).
  2. **Shared Live Markdown Artifact** (section-safe agent writes + optimistic 3-way human co-editing with conflict resolution).
  3. **Checkpoint Timeline & Live SSE Bus** (monotonic `seq`, heartbeats, `Last-Event-ID` zero-loss reconnect).
- **Direct manipulation primitives:** One-click **Interrupt (`Alt+P`)** ("Paused — state kept"), **Lock** (immutable protection from replans), **Edit**, **Expand**, **Mid-Task Requirement Injection** (minimal surgical replan), and **Non-Destructive Rollback**.
- **Adaptive Behavior Layer (`L1` / `L2` / `L3`):** Rolling `N = 8` window override rate with `[0.10, 0.40]` hysteresis and 5-action cooldown automatically calibrates when to ask vs. run freely.

## Slide 4 — Live Demo Script (3 Minutes)
1. **Launch (0:00–0:30):** Enter `P01` on Co-Plan (`:5173`); Latin-square assignment auto-loads *Municipal Urban Microgrid Policy Research Brief*. Hierarchical plan streams live via SSE.
2. **Watch & Lock (0:30–1:00):** Step 1 & Step 2 complete; click **Lock** on Step 2 (*Evidence Synthesis*) to freeze verified facts.
3. **Interrupt & Steer Mid-Flight (1:00–1:30):** Click **Interrupt (`Alt+P`)** while Step 3 streams -> in-flight LLM call cancels immediately, status shows **"Paused — state kept"**. Edit Step 3 or add a steering note and **Resume**.
4. **Mid-Task Requirement Pivot (1:30–2:15):** Open **Requirement Change (`Alt+R`)**, inject the council's 40% low-income equity & `$2.5M` cap directive. Show: Step 2 stays **locked & untouched**, only affected downstream steps are marked **Invalidated**, and `first_useful_response` fires immediately.
5. **Co-Edit & Roll Back (2:15–3:00):** Edit Markdown directly (`Ctrl+S`), then demonstrate one-click **Roll Back Here** on an earlier checkpoint and show the preserved rollback audit log + adaptive autonomy adjustment (`L3 -> L2` with human-readable reason).

## Slide 5 — Controlled Evaluation Study Design
- **Strict experimental control:** Identical `llm_client.py`, model, `temperature`, `max_tokens`, `top_p`, `SHARED_SYSTEM_PROMPT`, and `SHARED_TOOL_REGISTRY` across Co-Plan (`:5173`) and Baseline (`:5174`).
- **Within-subjects Latin square:** `N = 12` (`eval/counterbalancing.csv`), 3 matched tasks (*Research Brief*, *Event Plan*, *Data-Analysis Report*), scripted mid-task requirement change at ~50% progress.
- **Preregistered hypotheses (`eval/PREREGISTRATION.md`):**
  - **H1:** Lower cognitive load (Raw NASA-TLX, 6 subscales)
  - **H2:** Shorter recovery time (`ts(first_useful_response) - ts(requirement_change_sent)`)
  - **H3:** Higher perceived control & agency (6-item 7-pt Likert)
  - **H4:** Non-inferior deliverable quality (`Δ = -0.75` on 0–10 blind dual-rater rubric)
- **Statistical rigor:** Shapiro-Wilk -> paired t-test / Wilcoxon, Cohen's `dz` / rank-biserial `r`, 95% bootstrap CIs, Holm-Bonferroni across H1–H4, AB/BA carryover checks, blind dual-rater Cohen's κ.

## Slide 7 — Real Engineering Failure Cases Found & Fixed (from `eval/failure_cases.md`)
- **FC-01 (`adaptive.py`):** `L1` confidence gate `1.01` triggered Pydantic `<= 1.0` validation error -> fixed to `1.00` with explicit `L1` check.
- **FC-02 (`routes.py`):** SSE reconnect with `close_on_done=true` stopped on the *first* `done` after a rollback-and-resume cycle -> fixed by comparing `seq >= latest_seq`.
- **FC-03 (`pyproject.toml`):** Multi-directory flat layout broke editable installs -> fixed with explicit `backend*` package discovery.
- **FC-04 (`routes.py` / `sse-starlette`):** `AppStatus.should_exit_event` cached a stale asyncio loop across sequential SSE drop/reconnect tests -> fixed by resetting stale loop bindings before creating `EventSourceResponse`.

## Slide 8 — Limitations & Next Steps
- **Limitations:**
  - Single-user local SQLite architecture (no multi-user CRDT sync yet).
  - Co-Plan's `first_useful_response` measures plan-level recovery while Baseline measures full-draft regeneration—must always be interpreted alongside total completion time and H4 blind quality.
  - Real-world LLM latency/rate-limit variance can affect perceived responsiveness (mitigated via 429 exponential backoff, timeout handling, and single-shot JSON planner repair).
- **Next Steps:**
  1. Complete `N = 2–3` pilot runs with a live LLM (`STUDY_PROTOCOL.md` pilot checklist).
  2. Run full counterbalanced `N = 12` (or `N = 24`) study and blind dual-rater scoring.
